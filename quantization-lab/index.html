GEMM Precision

以 linear projection Y = A Wᵀ 为例。W 的每一行对应一个 output channel；上方配置决定 storage、operands 和 accumulator dtype。

Tile-level Dequantization

优化 kernel 通常按 tile 读取 W，并在片上完成所需的 dtype conversion。GPU DRAM 中保留压缩格式；Registers / Shared Memory 的临时空间随 kernel 迭代复用。下一 token 可能再次读取 W，无需重新从 SSD 加载整个模型。

Symmetric Uniform Quantization

调整 bit-width 和 clipping range，查看 quantized values、reconstruction 与 quantization error。这里使用数值模型，不运行 LLM。

Reference quantizer: z = 0，q ∈ [−qmax, qmax]，round-to-nearest, ties-to-even。INT4 使用 [−7, 7] 共 15 个值；4 bit 有 16 种编码。其他 quantizer 可使用 [−8, 7]、asymmetric quantization 或 non-uniform codebook。

Additional Runtime Memory

还包括 quantization scales、zero points、alignment / padding，保留高精度的 embedding / LM head / norm parameters，以及 activations、workspace、allocator、CUDA graph 与可能的高精度 KV residual buffer。

示例：每 128 个 W4 values 额外保存一个 2-byte scale，7B values 约需 104 MiB scale metadata。真实格式可能还有 zero point 或 progressive quantization parameters。

Model Assumptions

Single discrete NVIDIA GPU；模型放得下 GPU DRAM；无 offload / distributed inference / prefix cache。采用 Llama-style pre-norm、RoPE、SwiGLU 与 GQA。Activation / residual boundaries 默认 FP16；norm / softmax reductions 和 floating-point GEMM accumulators 使用 FP32。

L2 位于 SM 之外；Shared Memory 和 Registers 位于 SM 内。Shared staging 和 attention 的 CUDA / Tensor Core mapping 取决于 kernel。硬件图只表示 operator-level reference dataflow，不是 profiler trace 或 chip floorplan。Kernel fusion 可消除部分 DRAM 中间结果；图中以 Write* 标注。

Checkpoint conversion 在图中以 CPU offline preparation 示意，实际也可在 GPU 上进行。技术核查：2026-10-26。
