W4A16：一块权重怎样进入 GPU 计算

按 tile 读取与反量化的示意路径；动画表达数据方向，不表达真实耗时。cache/shared 的路径因内核而异。

Long-lived weights

  • • Checkpoint is usually loaded once.
  • • The GPU retains packed low-bit weights.
  • • A new decode step can read weights again.

Tile-local conversion

  • • Only the current tile is reconstructed.
  • • Temporary FP16 values live on-chip.
  • • Fusion may avoid an output DRAM write.

Scope

  • • A teaching W4A16 execution path.
  • • Actual cache/shared routes vary.
  • • Neither HBM nor shared memory computes.
