先建立三个位置概念

数字存在哪，和数字怎么算，分开看。

A

显存保管大数据

模型权重和每层 KV cache 常驻 GPU 显存。HBM 是显存的一种；A100 用 HBM，L40S 用 GDDR6。

B

片上空间暂存小块

共享内存供一个线程块协作；寄存器保存线程正在使用的数据与累加结果。容量较小，需要分块复用。

C

计算单元执行指令

Tensor Core 擅长矩阵乘法；CUDA Core 等通用执行单元处理解包、缩放、归一化和逐元素操作。

范围、依据与简化

哪些是论文事实，哪些是教学约定？

这里明确采用的范围

  • 主线展开一个 Llama 风格、带 RoPE 和 SwiGLU 的 Transformer block；每层拥有自己的权重与 KV cache。
  • QServe 模式以 W4A8KV4 g128 解释分组重建。论文 A100 主基准采用 per-channel，L40S 采用 per-group；这里不比较性能。
  • Embedding、最终 LM head 和采样用于接全流程，示意采用 FP16 张量；不据此声称 QServe 对这些部件的真实精度。
  • Prefill 展示数学依赖与张量精度；FP16 基础模式是教学设定。QServe 解码 attention 的算子级描述来自论文，未逐条审计 softmax/归约指令精度。
  • 不运行真实 LLM，不模拟真实延迟；示例数值不代表真实模型输出。重建为 FP16 不会恢复已经丢失的信息。
